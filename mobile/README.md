# اپلیکیشن اندروید لیگ قهرمانان مالیاتی

نسخه اولیه Flutter شامل ورود با شماره همراه و کد یک‌بارمصرف، نمایش آزمون‌های منتشرشده، تاریخچه نتایج، رتبه لیگ، جدول برترین‌ها و ثبت اعتراض از روی نتیجه است.

## راه‌اندازی
1. Flutter SDK و Android SDK را نصب کنید.
2. در این پوشه اجرا کنید: `flutter pub get`
3. نشانی واقعی API را تعیین کنید: `flutter run --dart-define=API_BASE_URL=https://api.example.ir`

پس از تنظیم سرویس پیامک در سرور، کاربر می‌تواند با OTP وارد شود. توکن دریافتی با flutter_secure_storage در حافظه امن دستگاه ذخیره می‌شود.

## نکات و محدودیت‌ها
- نشانی API نمونه است و باید با دامنه واقعی HTTPS جایگزین شود.
- سرویس ارسال پیامک در backend هنوز پیکربندی نشده؛ تا آن زمان درخواست کد ورود با پاسخ 503 مواجه می‌شود.
- فهرست نتایج از API شخصی‌سازی‌شده دریافت می‌شود؛ فقط نتایج نهایی همان کاربر نمایش داده می‌شود.
- با لمس نتیجه می‌توان فرم اعتراض را باز کرد؛ اعتبار و مهلت اعتراض در سرور بررسی می‌شود.
- فهرست آزمون‌ها فعلاً فقط نمایشی است؛ رابط پاسخ‌گویی به سؤال‌ها و اجرای آزمون در موبایل مرحله بعدی است.
- اجرای Flutter، ساخت APK و تست روی دستگاه هنوز انجام نشده است.

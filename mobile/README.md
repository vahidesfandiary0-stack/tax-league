# اپلیکیشن اندروید لیگ قهرمانان مالیاتی

پوسته اولیه Flutter برای مشاهده رتبه و امتیاز، جدول برترین‌ها، ثبت اعتراض و پیگیری وضعیت اعتراض.

## راه‌اندازی
1. Flutter SDK و Android SDK را نصب کنید.
2. در این پوشه اجرا کنید: `flutter pub get`
3. نشانی واقعی API را تعیین کنید: `flutter run --dart-define=API_BASE_URL=https://api.example.ir`

توکن API با flutter_secure_storage در حافظه امن دستگاه ذخیره می‌شود.

## محدودیت‌های نسخه اولیه
- نشانی API نمونه است و باید با دامنه واقعی جایگزین شود.
- ورود پیامکی و دریافت خودکار توکن هنوز به رابط ورود متصل نیست.
- برای ثبت اعتراض، UUID نتیجه آزمون باید دستی وارد شود؛ تاریخچه نتایج و انتخاب خودکار هنوز ساخته نشده.
- اجرای Flutter، ساخت APK و تست روی دستگاه هنوز انجام نشده است.

# اپلیکیشن اندروید لیگ قهرمانان مالیاتی

نسخه اولیه Flutter شامل ورود با شماره همراه و کد یک‌بارمصرف، فهرست آزمون‌ها، شرکت در آزمون زمان‌دار، ذخیره پاسخ‌ها روی سرور، تحویل آزمون، تاریخچه نتایج، رتبه لیگ و ثبت اعتراض است.

## راه‌اندازی
1. Flutter SDK و Android SDK را نصب کنید.
2. در این پوشه اجرا کنید: `flutter pub get`
3. نشانی واقعی API را تعیین کنید: `flutter run --dart-define=API_BASE_URL=https://api.example.ir`

پس از پیکربندی سرویس پیامک در backend، کاربر می‌تواند با OTP وارد شود. توکن دریافتی با flutter_secure_storage در حافظه امن دستگاه ذخیره می‌شود.

## چرخه شرکت در آزمون
- کاربر آزمون منتشرشده را انتخاب می‌کند.
- سرور تلاش آزمون و زمان پایان را تعیین می‌کند و یک نسخه ثابت از سؤال‌ها و گزینه‌ها برمی‌گرداند.
- با انتخاب هر گزینه، پاسخ به API ارسال و در سرور ذخیره می‌شود.
- با بازگشت به تلاش فعال، گزینه ذخیره‌شده دوباره در رابط انتخاب‌شده نمایش داده می‌شود.
- زمان‌سنج از deadline سرور محاسبه می‌شود؛ در پایان زمان، برنامه درخواست تحویل می‌فرستد.
- امتیاز و تعداد پاسخ‌های صحیح/غلط/نزده فقط توسط backend محاسبه می‌شود. برنامه موبایل هیچ کلید پاسخ صحیحی دریافت نمی‌کند.

## APIهای استفاده‌شده
- `POST /api/v1/auth/request-otp/`
- `POST /api/v1/auth/verify-otp/`
- `GET /api/v1/exams/`
- `POST /api/v1/exams/{exam_id}/start/`
- `POST /api/v1/exams/attempts/{attempt_id}/answers/`
- `POST /api/v1/exams/attempts/{attempt_id}/finalize/`
- `GET /api/v1/exams/results/`

## محدودیت‌ها و نکات قبل از انتشار
- سرویس ارسال پیامک هنوز پیکربندی نشده؛ تا آن زمان درخواست کد ورود با پاسخ 503 مواجه می‌شود.
- نشانی API نمونه است و باید با دامنه واقعی HTTPS جایگزین شود.
- رابط فعلی اجرای آزمون نسخه اولیه است؛ قطع و وصل اینترنت، retry صف پاسخ‌ها، هشدار خروج از آزمون و آزمون‌های دسترس‌پذیری هنوز تکمیل نشده‌اند.
- اجرای Flutter، ساخت APK و تست روی دستگاه هنوز انجام نشده است.

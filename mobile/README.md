# اپلیکیشن اندروید لیگ قهرمانان مالیاتی

نسخه اولیه Flutter شامل ورود با شماره همراه و کد یک‌بارمصرف، فهرست آزمون‌ها، شرکت در آزمون زمان‌دار، ذخیره پاسخ‌ها روی سرور، تحویل آزمون، تاریخچه نتایج، رتبه لیگ و ثبت اعتراض است.

## راه‌اندازی
1. Flutter SDK و Android SDK را نصب کنید.
2. در پوشه `mobile` برای ساخت فایل‌های بومی اندروید اجرا کنید: `flutter create --platforms=android --project-name tax_league .`
3. وابستگی‌ها را نصب کنید: `flutter pub get`
4. نشانی واقعی API را تعیین کنید: `flutter run --dart-define=API_BASE_URL=https://api.example.ir`
5. برای ساخت APK آزمایشی: `flutter build apk --debug --dart-define=API_BASE_URL=https://api.example.ir`

پس از پیکربندی سرویس پیامک در backend، کاربر می‌تواند با OTP وارد شود. توکن دریافتی با flutter_secure_storage در حافظه امن دستگاه ذخیره می‌شود.

## چرخه شرکت در آزمون
- کاربر آزمون منتشرشده را انتخاب می‌کند.
- سرور تلاش آزمون و زمان پایان را تعیین می‌کند و یک نسخه ثابت از سؤال‌ها و گزینه‌ها برمی‌گرداند.
- با انتخاب هر گزینه، پاسخ به API ارسال و در سرور ذخیره می‌شود.
- با بازگشت به تلاش فعال، گزینه ذخیره‌شده دوباره در رابط انتخاب‌شده نمایش داده می‌شود.
- زمان‌سنج از deadline سرور محاسبه می‌شود؛ در پایان زمان، برنامه درخواست تحویل می‌فرستد.
- امتیاز و تعداد پاسخ‌های صحیح/غلط/نزده فقط توسط backend محاسبه می‌شود. برنامه موبایل هیچ کلید پاسخ صحیحی دریافت نمی‌کند.

## APIهای استفاده‌شده
- `POST /api/v1/auth/request-otp/`
- `POST /api/v1/auth/verify-otp/`
- `GET /api/v1/exams/`
- `POST /api/v1/exams/{exam_id}/start/`
- `POST /api/v1/exams/attempts/{attempt_id}/answers/`
- `POST /api/v1/exams/attempts/{attempt_id}/finalize/`
- `GET /api/v1/exams/results/`

## وضعیت ساخت و انتشار
- گردش‌کار CI برای Flutter format/analyze و ساخت APK دیباگ تنظیم شده است.
- یک APK دیباگ با موفقیت ساخته و به‌عنوان artifact در GitHub Actions بارگذاری شده است؛ [اجرای ساخت موفق](https://github.com/vahidesfandiary0-stack/tax-league/actions/runs/43228274686).
- هر artifact آزمایشی موقت است و نسخه امضاشده انتشار محسوب نمی‌شود.
- گردش‌کار ساخت APK امضاشده از مسیر دستی [Android signed release](https://github.com/vahidesfandiary0-stack/tax-league/actions/workflows/android-release.yml) اجرا می‌شود و به چهار GitHub Actions secret نیاز دارد: `ANDROID_KEYSTORE_BASE64`، `ANDROID_KEYSTORE_PASSWORD`، `ANDROID_KEY_ALIAS` و `ANDROID_KEY_PASSWORD`. این secrets باید فقط در تنظیمات امن مخزن ثبت شوند؛ کلید خصوصی یا رمزها را در کد یا گفتگو قرار ندهید.
- پیش از ساخت نسخه انتشار باید دامنه واقعی HTTPS سرویس API آماده و کلید امضای اختصاصی با پشتیبان امن تهیه شود.

## محدودیت‌ها و کارهای باقی‌مانده پیش از انتشار
- سرویس ارسال پیامک هنوز پیکربندی نشده؛ تا آن زمان درخواست کد ورود با پاسخ 503 مواجه می‌شود.
- نشانی API نمونه است و باید با دامنه واقعی HTTPS جایگزین شود.
- پاسخ‌های ارسال‌نشده هر تلاش آزمون در حافظه امن دستگاه نگه‌داری می‌شوند و با دکمه «ارسال پاسخ‌های ذخیره‌شده» دوباره فرستاده می‌شوند؛ تا ارسال موفق، تحویل آزمون غیرفعال است. این صف فقط روی همان دستگاه و همان نصب برنامه نگه‌داری می‌شود و جایگزین پشتیبان‌گیری سروری یا تست قطع اینترنت در دستگاه واقعی نیست.
- هشدار خروج از آزمون و آزمون‌های دسترس‌پذیری هنوز تکمیل نشده‌اند.
- APK دیباگ روی دستگاه فیزیکی و نسخه‌های مختلف Android هنوز آزمون میدانی نشده است.
- پیش از انتشار عمومی، آزمون امنیتی، تست بار backend، بررسی حریم خصوصی و تست کامل پرداخت و بازیابی حساب لازم است.

# لیگ قهرمانان مالیاتی

پروژه آزمون آنلاین و لیگ رقابتی مالیاتی. این مخزن در حال توسعه است و هنوز نسخه قابل اجرا یا منتشرشده محصول نیست.

## ساختار
- `backend/`: API و منطق کسب‌وکار با Django و Django REST Framework
- `mobile/`: اپلیکیشن Flutter با اولویت Android
- `admin-panel/`: پنل مدیریت وب
- `docs/`: مستندات محصول، معماری، API، امنیت، نقش‌های کارکنان و استقرار
- `infrastructure/`: زیرساخت استقرار و پشتیبان‌گیری
- `tests/`: آزمون‌های خودکار

## مدیریت نقش کارکنان
پس از نصب وابستگی‌ها و اجرای migrationها در پوشه `backend`، برای ساخت گروه‌های دسترسی محدود اجرا کنید:

```bash
python manage.py sync_staff_roles
```

شرح نقش‌ها و مجوزهای هر گروه در [مستند نقش‌های کارکنان](backend/docs/staff-roles.md) آمده است. فقط superuser باید حساب کارکنان و عضویت گروهی آن‌ها را مدیریت کند.

## چرخه فصل و رتبه‌بندی لیگ

قواعد فعال‌سازی/بستن فصل، دفتر امتیاز تغییرناپذیر و API تاریخچه رتبه‌ها در [مستندات لیگ](backend/apps/league/README.md) آمده است.

## آزمون‌های خودکار backend

برای اجرای محلی از ریشه مخزن: `python -m pip install -r backend/requirements.txt` و سپس `python -m pytest -q`. گردش‌کار GitHub Actions نیز در push و pull request به شاخه main تست‌ها را اجرا می‌کند. وضعیت موفقیت تست‌ها تا زمان مشاهده نتیجه اجرای workflow تأییدشده نیست.

## تنظیمات انتشار امن backend

برای انتشار از `config.settings.production` استفاده کنید، نه تنظیمات پایه. نمونه متغیرها در [.env.production.example](.env.production.example) و چک‌لیست در [راهنمای امنیت انتشار](backend/docs/production-security.md) قرار دارد. تنظیمات production بدون کلید قوی، PostgreSQL و دامنه‌های مجاز اجرا نمی‌شود.

## اصول امنیتی
- کلیدها، رمزها، توکن‌ها و اطلاعات بانکی واقعی را در Git ثبت نکنید.
- پاسخ صحیح و نمره‌دهی فقط در سرور نگهداری و محاسبه شود.
- آزمون منتشرشده باید snapshot تغییرناپذیر سؤال‌ها داشته باشد.
- پرداخت انتقال بانکی فقط پس از بررسی مدیر و ثبت سابقه تأیید شود.
- شماره کارت فقط در تنظیمات امن پنل مدیر باشد، نه در API عمومی.
- هر نقش کارکنان فقط مجوزهای موردنیاز خود را دریافت کند.

## وضعیت فعلی
اسکلت backend و بخش‌هایی از حساب/OTP، بانک سؤال، آزمون، لیگ، پرداخت دستی، اشتراک، اعلان، پشتیبانی و کنترل دسترسی کارکنان در مخزن ثبت شده‌اند. تست‌های خودکار نوشته شده‌اند، اما هنوز اجرای کامل تست‌ها، بررسی امنیتی، راه‌اندازی سرویس، اتصال پیامک، ساخت اپ Android و استقرار انجام نشده است. هیچ ظرفیت یا آمادگی عملیاتی تأییدشده‌ای اعلام نمی‌شود.

# خط مبنای امنیت

- احراز هویت و مجوز دسترسی باید در هر endpoint بررسی شود.
- هیچ‌گاه پاسخ صحیح، کلید خصوصی یا شماره کارت در پاسخ عمومی API قرار نگیرد.
- نمره‌دهی و زمان‌بندی آزمون فقط در سرور انجام شود.
- عملیات حساس با تراکنش پایگاه داده، کنترل تکرار درخواست و audit log محافظت شوند.
- فایل رسید پرداخت در فضای خصوصی ذخیره و فقط برای کاربر مجاز و مدیر قابل دسترسی باشد.
- محدودسازی نرخ برای OTP، ورود و ارسال پاسخ اعمال شود.
- استقرار عمومی فقط با HTTPS، تنظیمات production و مدیریت امن secret مجاز است.
- آزمون نفوذ و بار فقط روی محیطی انجام شود که مالک آن مجوز داده است.

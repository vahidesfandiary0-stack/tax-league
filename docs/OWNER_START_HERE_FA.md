# راهنمای شروع مالک پروژه — فقط کارهای ضروری

این راهنما برای مالک پروژه‌ای است که با سرور، دامنه و انتشار اپ آشنایی فنی ندارد. کد و گردش‌کارهای خودکار پروژه در مخزن آماده شده‌اند؛ اما سرویس واقعی بدون خرید/ایجاد منابع و ثبت اسرار اختصاصی مالک قابل راه‌اندازی نیست.

## چه چیزهایی را من در مخزن آماده کرده‌ام؟
- API و اپ Android و تست‌های خودکار
- Dockerfile و Docker Compose برای backend و PostgreSQL
- نمونه متغیرهای محیطی و چک‌لیست امنیتی
- گردش‌کار ساخت APK آزمایشی و گردش‌کار ساخت APK انتشار امضاشده

آماده بودن فایل‌های بالا به معنی خرید VPS، ثبت دامنه، نصب TLS، فعال بودن پیامک یا استقرار واقعی نیست.

## فقط سه مورد مالک لازم است

### ۱) تهیه VPS و دامنه
برای شروع آزمایشی یک VPS لینوکسی با Ubuntu LTS، حداقل ۲ هسته CPU و ۴ گیگابایت RAM پیشنهاد شده است. این مقدار ظرفیت نهایی را تضمین نمی‌کند؛ ظرفیت فقط با تست بار مشخص می‌شود. دامنه باید در حساب خود مالک ثبت شود و DNS آن در اختیار مالک باشد. ترجیح پروژه میزبانی داخل ایران است، مشروط به کیفیت شبکه، پشتیبان‌گیری و دسترسی پایدار.

**نکته:** من نمی‌توانم از حساب یا پول مالک خرید انجام دهم یا شرایط قرارداد را به‌جای او بپذیرم. پیش از خرید، قیمت تمدید، محل دیتاسنتر، امکان snapshot/backup، محدودیت ترافیک و پشتیبانی را بررسی کنید.

### ۲) ساخت حساب سرویس پیامک
برای شروع، آداپتور **کاوه‌نگار** در کد آماده شده است و از VerifyLookup و الگوی OTP استفاده می‌کند. در [مستندات رسمی کاوه‌نگار](https://kavenegar.github.io/kavenegar_fa/) حساب بسازید، امکان VerifyLookup/الگوی خدماتی را از پشتیبانی تأیید کنید و نام الگوی تأییدشده را بگیرید. سپس فقط این سه مقدار در Secret Manager سرور ثبت می‌شود: `SMS_PROVIDER=kavenegar`، `KAVENEGAR_API_KEY` و `KAVENEGAR_OTP_TEMPLATE`. **رمز یا API token را در گفتگو ارسال نکنید.** تا وقتی حساب، کلید و الگوی تأییدشده وجود نداشته باشد، endpoint درخواست OTP عمداً کد را افشا نمی‌کند و با خطای 503 پاسخ می‌دهد.

### ۳) ساخت کلید امضای Android
برای انتشار، کلید امضای اختصاصی لازم است. این کلید را باید در محیط امن ایجاد و دو نسخه پشتیبان رمزگذاری‌شده از آن نگهداری کرد. چهار مقدار زیر فقط در GitHub → Settings → Secrets and variables → Actions مخزن ثبت شوند:
- ANDROID_KEYSTORE_BASE64
- ANDROID_KEYSTORE_PASSWORD
- ANDROID_KEY_ALIAS
- ANDROID_KEY_PASSWORD

**فایل keystore و رمزهای آن را در چت، ایمیل عمومی یا Git قرار ندهید.** گم شدن کلید می‌تواند به‌روزرسانی نصب‌های قبلی را دشوار یا ناممکن کند.

## مواردی که قبل از انتشار عمومی باید انجام شوند
- اتصال و آزمون پیامک واقعی
- رمزنگاری داده بانکی ذخیره‌شده یا انتقال آن به secret store
- اسکن بدافزار رسیدهای پرداخت و ذخیره‌سازی خصوصی
- پشتیبان رمزگذاری‌شده خارج از VPS و آزمون بازیابی
- استقرار HTTPS و بررسی هدرها و تنظیمات production
- آزمون کامل روی گوشی واقعی، امنیت و بار
- ساخت APK امضاشده با دامنه API واقعی
- تأیید مالک درباره مجوز استفاده از عنوان/برند و هرگونه ادعای وابستگی سازمانی

## حریم خصوصی و اطلاعات ممنوع برای ارسال در چت
رمز VPS، رمز پنل دامنه، کلید خصوصی، keystore، رمز دیتابیس، API token پیامک، شماره کارت و اطلاعات بانکی را در گفتگو ننویسید. از فرم امن و secret manager ارائه‌دهنده استفاده کنید.

## وضعیت نسخه آزمایشی
آخرین APK دیباگ با موفقیت در CI ساخته شده است؛ API آن هنوز به دامنه واقعی وصل نیست و برای انتشار عمومی مناسب نیست. وضعیت اجرای CI را در صفحه Actions مخزن ببینید.

# احراز هویت با شماره تلفن

## درخواست کد
`POST /api/v1/auth/request-otp/`

نمونه بدنه:
```json
{"phone_number":"+989121234567"}
```

کد OTP شش رقمی، ۳ دقیقه اعتبار و حداکثر ۵ تلاش دارد. درخواست کد به‌صورت محدودشده است. پاسخ صحیح یا کد OTP هرگز در API بازگردانده نمی‌شود.

## تأیید کد
`POST /api/v1/auth/verify-otp/`

```json
{"phone_number":"+989121234567","code":"123456"}
```

در صورت موفقیت، حساب کاربر و توکن API ایجاد یا بازیابی می‌شود. برای درخواست‌های محافظت‌شده:
`Authorization: Token <token>`

## وضعیت اتصال پیامک
آداپتور ارائه‌دهنده پیامک هنوز پیکربندی نشده است. تا اتصال و آزمایش یک سرویس‌دهنده واقعی، درخواست OTP عمداً پاسخ 503 می‌دهد و ورود واقعی از طریق پیامک فعال نیست. برای محیط تولید، کلیدهای سرویس پیامک باید فقط در secretهای محیطی نگهداری شوند.

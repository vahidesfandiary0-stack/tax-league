# موتور آزمون

## API
- GET `/api/v1/exams/`: فهرست آزمون‌های منتشرشده (ورود لازم است).
- POST `/api/v1/exams/{uuid}/start/`: شروع یا بازیابی تلاش فعال.
- POST `/api/v1/exams/attempts/{uuid}/answers/`: ذخیره پاسخ با `question_id` و `option_id`.
- POST `/api/v1/exams/attempts/{uuid}/finalize/`: تحویل و نمره‌دهی سمت سرور.
- GET `/api/v1/exams/attempts/{uuid}/result/`: نتیجه تلاش تکمیل‌شده.

## قواعد پیاده‌سازی‌شده
- زمان شروع و مهلت پایان روی سرور ثبت می‌شود.
- سؤال‌ها و گزینه‌ها هنگام شروع در snapshot تلاش کپی می‌شوند؛ تغییر بانک سؤال، متن آزمون در حال اجرا را تغییر نمی‌دهد.
- API آزمون، شناسه و متن گزینه‌ها را می‌دهد و فیلد پاسخ صحیح را افشا نمی‌کند.
- هر پاسخ باید متعلق به همان تلاش و همان سؤال snapshot باشد.
- نمره‌دهی از داده سمت سرور انجام می‌شود؛ امتیاز پیشنهادی پیش‌فرض پاسخ صحیح +۱۰ و پاسخ غلط −۳ است.
- شروع مجدد، تلاش فعال همان کاربر را برمی‌گرداند؛ تلاش تکراری جدید بدون تمام شدن قبلی ساخته نمی‌شود.
- انتشار آزمون فقط از اکشن مدیریت و پس از اعتبارسنجی سؤال‌های منتشرشده مجاز است.

## موارد باقی‌مانده پیش از بهره‌برداری
- اتصال مجوز اشتراک/خرید به شروع آزمون.
- افزودن کلید idempotency برای درخواست‌های پاسخ و ثبت رویداد ممیزی.
- تعیین تکلیف دقیق سیاست تحویل زودهنگام و پایان خودکار تلاش‌های منقضی‌شده با worker.
- ثبت نتیجه در دفتر امتیاز لیگ فقط یک‌بار و با تراکنش مستقل.
- تست هم‌زمانی روی PostgreSQL، تست بار و بررسی امنیتی؛ تست‌ها هنوز اجرا نشده‌اند.

# پنل مدیریت وب

پنل مدیریت بر پایه Django Admin است و از مسیر `/admin/` در دسترس خواهد بود.

## داشبورد و بررسی اعتراض‌های لیگ
- داشبورد مدیریتی: `/admin/overview/` (فقط superuser)
- صف بررسی اعتراض‌ها: `/admin/league/appeals/` (superuser یا کارمند دارای مجوزهای مدیر لیگ)
- تصمیم تأیید/رد اعتراض از طریق سرویس کنترل‌شده ثبت می‌شود.
- تأیید اعتراض نیازمند ثبت توضیح و مقدار اصلاح امتیاز غیرصفر است.
- اصلاح امتیاز به دفتر جداگانه افزوده می‌شود؛ رکورد اصلی نتیجه آزمون تغییر نمی‌کند.

نقش‌های کارکنان با فرمان `python manage.py sync_staff_roles` ایجاد/به‌روزرسانی می‌شوند. فقط superuser باید عضویت کارکنان در گروه‌ها را مدیریت کند.

## وضعیت رابط
صفحه بررسی اعتراض‌ها و پیوند آن در داشبورد پیاده‌سازی شده است. سایر بخش‌های مدیریتی از Django Admin استفاده می‌کنند. این صفحات هنوز در محیط واقعی اجرا یا آزموده نشده‌اند.

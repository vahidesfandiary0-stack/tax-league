# اعلان‌های داخل برنامه

اعلان‌ها در پایگاه داده ذخیره می‌شوند و فقط برای صاحب حساب قابل مشاهده‌اند.

- `GET /api/v1/notifications/`: دریافت حداکثر ۱۰۰ اعلان اخیر
- `POST /api/v1/notifications/{id}/read/`: علامت‌گذاری اعلان به‌عنوان خوانده‌شده

انواع فعلی: تأیید/رد پرداخت، فعال‌شدن اشتراک و ثبت نتیجه آزمون.

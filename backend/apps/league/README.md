# لیگ قهرمانان مالیاتی

## چرخه فصل
- فصل فقط در بازه زمانی تعریف‌شده قابل فعال‌سازی است.
- در دیتابیس حداکثر یک فصل با وضعیت فعال پذیرفته می‌شود.
- بستن فصل فقط پس از رسیدن زمان پایان برنامه‌ریزی‌شده مجاز است.
- فعال‌سازی و بستن فصل از طریق actionهای پنل مدیریت و سرویس‌های کنترل‌شده انجام می‌شود.
- هر انتقال وضعیت، عامل و زمان و یادداشت اختیاری را در LeagueSeasonEvent ثبت می‌کند.
- فصل فعال و بسته‌شده از نظر عنوان و تاریخ‌ها قابل ویرایش نیست؛ سوابق رویداد نیز در پنل فقط‌خواندنی هستند.

## دفتر امتیاز و رتبه‌بندی
- برای هر تلاش آزمون حداکثر یک LeagueScoreEntry ثبت می‌شود.
- امتیاز از نتیجه نهایی تلاش در سمت سرور گرفته می‌شود؛ داده امتیاز از کاربر دریافت نمی‌شود.
- رکورد امتیاز از طریق مدل و پنل مدیریت قابل ویرایش یا حذف نیست.
- اگر آزمون خارج از بازه هر فصل فعال نهایی شود، نتیجه آزمون ثبت می‌شود اما به جدول رسمی فصل اضافه نمی‌شود.
- رتبه‌بندی بر اساس مجموع امتیاز، تعداد پاسخ صحیح، تعداد پاسخ غلط کمتر، زمان کل کمتر و شناسه کاربر به‌عنوان معیار قطعی نهایی مرتب می‌شود.
- API جدول و آمار شخصی می‌تواند فصل فعال یا یک فصل بسته‌شده را با پارامتر season نمایش دهد. limit جدول بین ۱ تا ۵۰۰ است.

## API
- GET /api/v1/league/season/
- GET /api/v1/league/leaderboard/?season=<uuid>&limit=100
- GET /api/v1/league/me/?season=<uuid>

تست‌های چرخه فصل، دفتر امتیاز و تاریخچه در backend/tests/test_league.py قرار دارند. اجرای تست‌ها در محیط CI هنوز تأیید نشده است.

# چرخه آزمون

## یکپارچگی زمان و نمره‌دهی

- زمان شروع و پایان از ساعت سرور محاسبه می‌شود؛ ساعت دستگاه کاربر معتبر نیست.
- شروع آزمون در لحظه پایان بازه مجاز نیست.
- مهلت پاسخ‌گویی هر تلاش، کوچک‌ترِ «زمان شروع + مدت آزمون» و «پایان بازه انتشار آزمون» است.
- هر کاربر برای هر آزمون حداکثر یک تلاش فعال دارد؛ قید یکتا در دیتابیس نیز این موضوع را پشتیبانی می‌کند.
- ثبت پاسخ پس از deadline رد می‌شود و گزینه باید متعلق به همان سؤال در همان snapshot باشد.
- پاسخ صحیح و امتیازها از snapshot سمت سرور محاسبه می‌شوند؛ API گزینه صحیح را به کاربر نمی‌فرستد.
- نهایی‌سازی idempotent است؛ درخواست تکراری نتیجه جدید یا اعلان تکراری ایجاد نمی‌کند.
- تلاش منقضی‌شده با وضعیت expired نهایی می‌شود؛ نتیجه فقط پس از نهایی‌سازی در دفتر امتیاز لیگ ثبت خواهد شد.

تست‌های این رفتارها در backend/tests/test_exams.py قرار دارند. اجرای آن‌ها هنوز در محیط پروژه انجام نشده است.

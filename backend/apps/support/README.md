# پشتیبانی درون‌برنامه‌ای

کاربر می‌تواند درخواست پشتیبانی بسازد، پیام‌های قبلی را ببیند و در همان درخواست پاسخ دهد. مدیران و کارکنان پشتیبانی می‌توانند همه درخواست‌ها را ببینند، پاسخ دهند و وضعیت را تغییر دهند.

## API

- `GET /api/v1/support/tickets/`: فهرست درخواست‌های خود کاربر؛ کارکنان فهرست همه درخواست‌ها را می‌بینند.
- `POST /api/v1/support/tickets/`: ایجاد درخواست با `subject`, `category`, `first_message`.
- `GET /api/v1/support/tickets/{uuid}/`: مشاهده جزئیات و سوابق پیام.
- `POST /api/v1/support/tickets/{uuid}/messages/`: ارسال پیام در درخواست.
- `PATCH /api/v1/support/tickets/{uuid}/status/`: تغییر وضعیت فقط برای کارکنان.

احراز هویت لازم است. شناسه تماس یا شماره تلفن در خروجی API نمایش داده نمی‌شود. کاربران فقط به درخواست‌های خود دسترسی دارند.

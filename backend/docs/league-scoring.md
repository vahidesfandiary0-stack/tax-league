# دفتر امتیاز و اصلاح نتایج لیگ

## قواعد دفتر امتیاز
- هر تلاش رسمی حداکثر یک LeagueScoreEntry دارد؛ رابطه OneToOne و قید دیتابیس مانع ثبت تکراری است.
- رکورد اصلی امتیاز پس از ثبت قابل ویرایش یا حذف نیست.
- امتیاز اصلاحی در LeagueScoreAdjustment به‌صورت رکورد مستقل، همراه با کاربر ثبت‌کننده، علت، زمان و کلید تکرار ذخیره می‌شود.
- اصلاح فقط برای فصل بسته‌شده و توسط superuser یا عضو staff دارای مجوز league.add_leaguescoreadjustment انجام می‌شود.
- کلید تکرار یکسان با داده یکسان، همان اصلاح قبلی را برمی‌گرداند؛ استفاده از همان کلید برای اصلاح متفاوت رد می‌شود.
- رتبه‌بندی و آمار شخصی، مجموع امتیاز پایه و اصلاح‌های ثبت‌شده را نمایش می‌دهند.
- اصلاحات، سابقه اصلی آزمون را تغییر نمی‌دهند. برای برگشت یک اصلاح، باید اصلاح معکوس جدید با علت مستقل ثبت شود.

## بستن فصل
فصل فقط پس از رسیدن به ends_at از مسیر سرویس کنترل‌شده بسته می‌شود. هر فعال‌سازی و بستن فصل در LeagueSeasonEvent ثبت می‌شود. فصل بسته‌شده و رویدادهای آن قابل ویرایش یا حذف نیستند.

## محدودیت فعلی
این قابلیت دفتر امتیاز و اصلاحات را در backend فراهم می‌کند؛ هنوز رابط کاربری اختصاصی برای درخواست/بررسی اعتراض شرکت‌کنندگان وجود ندارد. اصلاح امتیاز صرفاً ابزار مدیریتی است و نباید بدون بررسی مستندات و ثبت علت استفاده شود.
